## Current Launcher Features

- [ ] Login with [OSMC](https://os-mc.net)
- [ ] Login with [golden's SSO](https://github.com/goldenboys2011/goldens-sso/)
- [x] Login with [Microsoft](https://microsoft.com)
- [x] Launches Beta 1.7.3 with player data
- [x] Save user data
- [ ] Launch multiple clients
- [x] Set specific RAM allocation


## Current Endlessly Client Features

1. Hacks
2. Server list
3. Helpful in-game commands
4. Custom capes
5. Fast resource pack change

### Commands

| Command     | Arguments          | Description                                      |
|-------------|--------------------|--------------------------------------------------|
| `osmctp`    | -                  | Creates one-use teleport location on os-mc.net   |
| `sethealth` | `<value>`          | Sets player's health to the given value          |
| `speed`     | `<value>`          | Sets speed multiplier for speed hack             |
| `jump`      | `<value>`          | Sets jump multiplier for jump hack               |
| `giveitem`  | `<id> <amount>`    | Gives item of `<id>` in `<amount>`               |
