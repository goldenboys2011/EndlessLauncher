# Contributing!

> EndlessLauncher

First of all thank you for wanting to **contribute**! Means a lot 💙!

## Before contributing tho take in mind:

### Use a new branch

Always create a new branch with the format:
```
yourname-version
```
For example:
```
golden-0.1
```

### Correct commit messages

Yes, you can have fun with the messages but they need to make sense at some degree.

### Make sure everything works

Talking from my experience on this project, the launcher is already broken and it wouldn’t be fun :(

### Clean code

Please write clean code as much as you can. The least you can do is add comments so we know what is what!
